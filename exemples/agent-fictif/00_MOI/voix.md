# Ma voix

> **Format d'une ligne** : `- [dit 2026-09] le fait` — le marqueur dit d'où ça vient, le mois
> dit depuis quand. `[dit ?]` si la date est inconnue.


Fichier lu uniquement quand un outil de la mallette doit **rédiger**.

**Les échantillons comptent plus que les règles**, et c'est l'inverse de ce qu'on croit : une
description de style est un mauvais guide pour imiter quelqu'un, alors que trois à cinq textes
réels suffisent. Les règles ci-dessous servent à trancher ce que les échantillons laissent
ambigu — elles ne les remplacent pas.

Il se construit par correction, pas par description : chaque fois que je réécris un texte
produit pour moi, l'écart est analysé et consigné ici. Et ce que j'ai réécrit moi-même se
conserve tel quel, jamais relissé.

Marqueurs : `[dit]` — `[vu]` — `[à confirmer]`

## Échantillons de référence

**La partie la plus importante de ce fichier.** Textes que j'ai écrits moi-même et qui me
ressemblent. Trois à cinq, pas davantage : au-delà, ça n'apporte plus rien. Rien qui contienne
un nom de client, une adresse ou un montant.

Priorité à ceux qui ont produit un effet réel — un appel, un message, un rendez-vous —
plutôt qu'à ceux que je trouve réussis. Note l'effet à côté de l'échantillon.
